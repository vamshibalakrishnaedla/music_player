# 🎵 Music Player

A simple and responsive Music Player Web Application built using **HTML, CSS, and JavaScript**. It provides an interactive interface to play music with basic playback controls.

## ✨ Features

- ▶️ Play and Pause music
- ⏭️ Next and Previous song controls
- 🎧 Display song title and artist name
- ⏱️ Track progress bar
- 🔊 Volume control
- 📱 Responsive user interface
- 🎨 Clean and user-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/MangaLokesh/Music-Player.git
   ```

2. Open the project folder:

   ```bash
   cd Music-Player
   ```

3. Open `index.html` in your browser.
